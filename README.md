## 💻 Quando o problema pede código

Nem tudo se resolve só administrando — às vezes a solução para um gargalo
de processo é provisionar algo que automatize ou estruture o fluxo.

**Frota** — solução para o controle de reserva da frota de veículos da
empresa, que era feito de forma manual e sem trilha de aprovação clara.
Estruturei um fluxo com duas etapas de aprovação e checklist fotográfico
obrigatório na retirada/devolução, autenticado contra o Active Directory
via LDAPS. Em desenvolvimento, ciclo funcional completo já testado.
*(Next.js, PostgreSQL — código privado)*

**Atendimento via WhatsApp integrado ao GLPI** — a abertura de chamado
dependia de contato manual e não deixava registro estruturado nem trilha
de auditoria consistente. Provisionei uma automação que recebe a mensagem
no WhatsApp, conduz uma coleta guiada de informação e registra o chamado
diretamente no GLPI, com histórico de conversa preservado e um painel
próprio para acompanhar volume e tempo de atendimento.
*(n8n, GLPI, Docker Compose)*

**MaxPanel** — ferramenta de linha de comando em PowerShell para
manutenção e diagnóstico de Windows: 40 funções organizadas por categoria,
com menu interativo e modo de automação via CLI.
🔗 [github.com/MatheusMaximo15/MaxPanel](https://github.com/MatheusMaximo15/MaxPanel)

**Bot de música para Discord** — bot em Python com fila de reprodução,
integração YouTube/Spotify/SoundCloud e sistema de usuários VIP.
*(código privado, projeto pessoal)*

**Bot de figurinhas para WhatsApp** — customização de um bot open-source
para conversão de imagem em figurinha, com funções extras de tradução e
remoção de fundo.
*(código privado, projeto pessoal)*
